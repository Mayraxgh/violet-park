¿Cómo funciona Violet Park?

El sensor ultrasónico mide la distancia entre el automóvil y el obstáculo mientras se realiza la maniobra de reversa.

Cuando el automóvil se encuentra a más de 20 cm, se activa el LED verde. Al acercarse, se enciende el LED amarillo. Entre más se aproxima, el LED rojo parpadea y el buzzer emite sonidos. A 3 cm o menos, ambos permanecen activados continuamente.

El LED blanco indica cuando se detecta contacto con el sensor táctil.
